# Programa Python - Control de Inventario
Este repositorio contiene la solución del problema 3 de programación en Python.

# Descripción
El programa permite analizar el inventario de una empresa y calcular automáticamente la cantidad de productos que deben solicitarse cuando el stock actual es menor al stock mínimo requerido.

# Funcionalidades
- Uso de matrices para almacenar datos.
- Uso de funciones en Python.
- Estructuras repetitivas y condicionales.
- Generación de reporte de inventario.
